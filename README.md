# 🪨 📄 ✂️ Rock Paper Scissors Game

A simple, interactive, console-based **Rock Paper Scissors** game written in Python. Play against a randomized AI opponent complete with an automated dramatic countdown timer!

## ✨ Features
* **Interactive Gameplay:** Play as many rounds as you want until you decide to exit.
* **Smart AI:** The computer randomly selects its move every turn.
* **Dramatic Suspense:** Includes a visual `3... 2... 1...` countdown before revealing the winner.
* **Easy Navigation:** Quickly type `no` at any prompt to exit the game gracefully.

## 🚀 How to Run the Game

### Prerequisites
Make sure you have **Python 3** installed on your system.

### Steps
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd YOUR-REPOSITORY-NAME
   ```
3. Run the game script:
   ```bash
   python main.py
   ```
   *(Note: Replace `main.py` with the actual filename of your script if it is named differently).*

## 🎮 How to Play
1. Launch the script and type `yes` to begin.
2. Choose your weapon by typing either **ROCK**, **PAPER**, or **SCISSOR**.
3. Wait for the countdown to see if you won, lost, or tied!
4. Type `no` whenever you want to exit the game loop and quit.

## 🛠️ Built With
* **Python 3**
* `random` module (for AI logic)
* `time` module (for the countdown effect)
